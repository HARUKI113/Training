# Training

筋力トレーニング，ランニング，食事，体組成をまとめて記録・管理するための個人用Webアプリです．

GitHub Pages上で動作する静的Webアプリとして作成しています．

## 目的

主な目標は，上半身を中心に筋肉を増やしながら，腹部を引き締めることです．

特に以下を重点的にトレーニングします．

- 背中
- 肩
- 上腕二頭筋
- 上腕三頭筋
- 胸
- 腹筋

ランニングも継続し，筋力・体力の両方を維持・向上させます．


## 基本的な考え方

### 筋力トレーニング

筋肉を大きくするためには，同じトレーニングを繰り返すだけではなく，少しずつ負荷を高めることを意識します．

例えば，

- 前回より1回多く行う
- 前回より少し重い重量を使う
- 同じ重量でフォームを改善する

などです．

回数の目安は，筋肥大を目的とする種目では主に8〜15回程度としています．

指定回数を余裕を持って達成できるようになった場合は，次回から少し重量を増やします．

毎セット完全に限界まで追い込むのではなく，基本的には「あと1〜3回程度できそう」という状態を目安にします．

WORKOUT画面にはセット間の休憩タイマーを備えています．初期値は90秒で，60秒・90秒・120秒から選択できます．マシンの大きな種目は90〜120秒，腕・腹部や自重種目は60〜90秒を目安にします．

最近の筋トレ記録は行をクリックすると編集できます．変更後に「変更」を押すと更新され，「キャンセル」を押すと元の記録に戻ります．


## トレーニング構成

現在の週間メニューは仮設定です．

使用するジムの器具や身体の状態，実際のトレーニング記録に応じて変更します．

器具構成に合わせた現在の週間メニューは以下です．ラットプルダウンと「ラットプルダウンマシン」は同じ背中種目として扱い，同日に重複して行いません．

| 曜日 | 内容 |
| --- | --- |
| 月 | Back + Core：ラットプルダウン，ダンベルロウ，アブドミナル（自宅はクランチ） |
| 火 | Chest + Arms：チェストプレス（自宅はプッシュアップ），ショルダープレス，アーム・カール＆エクステンション |
| 水 | Rest：休養（疲労が強ければ完全休養） |
| 木 | Full Body：自重・ダンベル脚種目，ラットプルダウン，チェストプレス，アブドミナル |
| 金 | Easy Cardio：ランニングマシン30〜40分。疲労時は自転車20〜30分 |
| 土 | Shoulders + Core：ショルダープレス，ダンベル・サイドレイズ，アブドミナル（自宅はクランチ） |
| 日 | Easy Run：ランニングマシン30〜40分。疲労時は自転車20〜30分 |

休養もトレーニングの一部として扱います．

自宅で行う場合は，マシン種目を無理に再現せず，プッシュアップ・クランチ・自重スクワット・ダンベルロウなどに置き換えます．

疲労や筋肉痛が強い場合は，無理に予定通り実施せず回復を優先します．


## ランニング

ランニングは筋力トレーニングとは別に管理します．

記録項目は主に以下です．

- 距離
- 運動時間
- 平均ペース
- Apple Watchのアクティブカロリー
- Apple Watchの総消費カロリー
- 平均心拍数
- ストレッチ時間

基本的には40分程度のイージーランを中心とします．

毎回タイムを狙うのではなく，筋力トレーニングの回復を妨げない程度の強度で行います．

## ストレッチ

ストレッチは筋力トレーニングとは別の回復・柔軟性管理として扱います．

ただし，

- 筋トレ終了後
- ランニング終了後

に行ったストレッチ時間を，その日の運動記録に追加できます．

## 食事

食事では極端な減量を行わず，筋肉を増やすために必要な栄養を確保しながら，不要なカロリーを減らす方針です．

特にタンパク質摂取を重視します．

### タンパク質

目安として1日約110g前後を基準としています．

主なタンパク質源は，

- 肉
- 魚
- 卵
- 納豆
- 豆腐
- 牛乳
- ヨーグルト
- プロテイン

などです．

プロテインは必須ではなく，通常の食事だけではタンパク質が不足する場合の補助として使用します．

### 栄養記録

食事画面では，タンパク質だけでなく以下を日ごとに記録します．

- カロリー
- タンパク質（P）
- 脂質（F）
- 炭水化物（C）
- 食物繊維

クイック追加には，ごはん・食パン・バナナ・卵・納豆・肉・魚など一般的な食品を登録しています．表示値は1食分の目安なので，量が違う場合は自由入力で調整します．

カロリー・脂質・炭水化物・食物繊維の目標値は，設定画面から任意で入力できます．個人差が大きいため，未設定でも合計値だけを確認できるようにしています．

朝食・昼食・夕食のチェックに加えて，食べたものをメモとして選択できます．食べたもののチェックだけでは量が分からないため，栄養合計にはクイック追加または自由入力を使用します．

## 食事の基本形

### 朝

基本的に，

- 白米
- 味噌汁

に加えて，

- 納豆
- 卵
- 鮭

などからタンパク質を追加します．

### 昼

学校では肉や魚などのタンパク質源をできるだけ追加します．

### 筋トレ前

筋トレの30分〜1時間程度前に，

- バナナ
- おにぎり
- プロテイン

などを必要に応じて摂取します．

### 夜

筋トレ後であっても，白米などの炭水化物を完全に抜くことはしません．

## 体組成

家庭用体組成計で以下を記録します．

- 身長
- 体重
- BMI
- 体脂肪率
- 筋肉量
- 内臓脂肪レベル
- 基礎代謝量
- 体内年齢

BMIは身長と体重から自動計算します．

## 測定条件

家庭用体組成計では，水分量や体温などによって体脂肪率や筋肉量が変動します．

そのため，できるだけ同じ条件で測定します．

推奨する基準は，

1. 朝起きる
2. トイレへ行く
3. 飲食前に測定

です．

朝に測定できない場合は，毎日入浴前など，同じ条件に統一します．

アプリでは，

- 朝・起床後
- 入浴前
- 入浴後
- その他

を記録できます．

入浴前後の両方を記録することも可能ですが，体重・体脂肪率等の推移を見る場合は，同じ測定条件のデータを使用します．

## 体重の見方

1日単位の体重変化はあまり重視しません．

水分や食事量によって体重は簡単に変動するため，

- 7日平均
- 月平均
- 長期的な変化

を中心に確認します．

体重だけを減らすことではなく，

- 筋トレ重量や回数が伸びている
- 背中や腕が大きくなっている
- 腹部が引き締まっている
- ランニング能力を維持できている

ことを重視します．

## データ保存
個人の体重やトレーニング記録はGitHubリポジトリには保存しません．

データはブラウザの`localStorage`に保存します．

そのため，GitHub Pagesを公開しても入力した体重等がGitHub上に公開されることはありません．

## GitHub Pagesで公開

このアプリはビルド不要の静的Webアプリです．リポジトリの`main`ブランチへ変更をpushすると，`.github/workflows/deploy-pages.yml`がGitHub Pagesへ自動デプロイします．

初回だけ，GitHubリポジトリのSettings > Pages > Build and deployment > Sourceで`GitHub Actions`を選択してください．その後，Actionsの実行が完了すると公開URLが表示されます．

詳しい設定は，[GitHub公式のカスタムワークフロー手順](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)を参照してください．

このアプリは個人のトレーニング記録を目的としたものです．

痛み，体調不良，強い疲労などがある場合は無理にトレーニングを行わず，必要に応じて専門家へ相談してください．
